## Chạy thử

```bash
python -m http.server 8080
```

Mở `http://localhost:8080/`; không mở qua `file://` vì app tải JSON bằng `fetch()`.

## Release gate — chạy trước mọi bản cập nhật

```bash
python -m py_compile tools/validate-data.py tools/validate-learning-content.py tools/audit-toeic-coverage.py tools/audit-question-evidence.py tools/audit-distractors.py tools/sync-version.py tools/patch-data.py tools/tests/test_remaining_content_review.py tools/tests/test_legacy_collocation_cleanup.py
python tools/validate-data.py
python tools/validate-learning-content.py
python tools/validate-part1-photo-assets.py
python tools/audit-toeic-coverage.py
python tools/audit-question-evidence.py
python tools/audit-distractors.py
python tools/sync-version.py --check
node --check assets/js/app.js
node --check sw.js
node tools/tests/runtime-render-smoke.mjs
python -m unittest discover -s tools/tests -p 'test_remaining_content_review.py' -v
python -m unittest discover -s tools/tests -p 'test_legacy_collocation_cleanup.py' -v
```

Sau đó chạy unit tests theo module và kiểm tra ZIP integrity + giải nén + chạy lại các validator. Không ghi deploy, remote CI hoặc QA thiết bị thật là PASS nếu chưa thực hiện.
