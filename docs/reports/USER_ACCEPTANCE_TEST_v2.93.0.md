# User Acceptance Test — TOEIC Dictionary v2.93.0

**Purpose:** one consolidated acceptance round for the v2.93.0 Full Source. Complete after deploying the package to the GitHub Pages repository. Record all findings in one pass; do not split into small releases unless a critical blocker requires an emergency fix.

## A. Deployment and PWA
- [ ] Deploy the complete v2.93.0 source to GitHub Pages.
- [ ] Confirm the UI shows v2.93.0.
- [ ] On a device that has used an earlier release, reload after the new Service Worker activates; verify the new cache is used and no blank/half-loaded screen appears.

- [ ] Test online → offline → reload → online/reconnect. Record which screens work offline and whether reconnect restores normal operation.

Expected: app loads consistently; no old JS module or missing asset error; no loss of local learner data.
