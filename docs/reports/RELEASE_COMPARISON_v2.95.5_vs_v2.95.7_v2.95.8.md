# Release comparison — v2.95.5 vs v2.95.7 and v2.95.8 decision

## v2.95.5

- Contains the five regression groups delivered over v2.95.1–v2.95.5.
- Preserves Robot Buddy's optional local read-only Learning Insights, the visual dashboard and its toggle.
- Contains 34 JavaScript regression suites and 54 Python test modules, including the original release-rotation utility/test. Its original rotation helper did not protect older reports referenced by active documentation.

## v2.95.7

- Based on v2.95.6 and applies a corrective privacy change: removes `robot-learning-insights.js`, the app's snapshot adapter, progress dashboard, analysis toggle, progress-based idle nudges and their regression suites.
- Preserves the head-only mascot, static dialogue library, Placement consent/skip, quick prompts, reminders, feature shortcuts and interaction/idle safeguards.
- Improves documentation consolidation and strengthens the existing release-document rotation utility with reference protection, dry-run-first behavior and regression tests.
- Its ZIP contains 74 generated `.pyc` files under `__pycache__`; these are build/runtime artifacts, not source and must not ship.
- Its local report records 33/33 JavaScript suites PASS and 53/54 Python modules completed; `test_validator.py` was not completed within that run window.

## v2.95.8 selection

The v2.95.8 merge also makes the non-sensitive app-context behavior more useful: the Buddy receives the current page and current learning item (not a learner profile) for context-aware guidance and idle suggestions.

| Area | Decision |
|---|---|
| Five defect fixes | Keep all from v2.95.5 |
| Robot Buddy Learning Insights | Keep opt-in, local, read-only snapshot analysis and the single visual dashboard; do not import v2.95.7's feature removal |
| Static dialogue, Placement onboarding, quick prompts, reminder/idle safeguards | Keep |
| Documentation consolidation | Adopt the v2.95.7 Master / Compatibility / README structure |
| Release report rotation | Adopt the v2.95.7 dry-run-first script and regression test; preserve referenced active review handoffs |
| Generated bytecode | Exclude all `__pycache__`, `.pyc` and `.pyo` files |
| Compatibility tombstones | Keep `learning-assistant.js` and `quick-help.js` as inert overlay-compatibility files; do not reactivate them |

## Verification boundary

v2.95.8 retains the 34 JavaScript suites and 54 Python test modules, strengthens release rotation to protect relative links in Master/README/CHANGELOG, and re-runs the complete local suites and repository/content audits. GitHub Actions, GitHub Pages deployment, physical-device layout, offline/reconnect and actual audible TTS remain external acceptance gates.
