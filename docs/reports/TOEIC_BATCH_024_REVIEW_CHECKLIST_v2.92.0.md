# TOEIC Batch 024 — Independent Review Checklist v2.92.0

**Purpose:** handoff for a second reviewer. No item is pre-approved by this document. Record a reviewer name/date and item-level verdict; do not change `editorialStatus` until an explicit independent decision is recorded.

## Review criteria

- **Language:** grammar, naturalness, register, level appropriateness and Vietnamese translation quality.
- **Answer key:** exactly one defensible correct answer; no ambiguity or hidden assumptions.
- **Distractors:** plausible, parallel in form, non-duplicative and contradicted by the source where appropriate.
- **Evidence:** every Listening `evidenceText` and Reading source label/quote points to the exact supporting source.
- **Instructional value:** item tests the intended skill, not trivia or accidental vocabulary clues.
- **Status:** mark `APPROVE`, `REVISE` or `REJECT`; include a concrete reason for every non-approval.
